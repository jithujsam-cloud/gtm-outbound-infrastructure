Klaroh

Client reporting for cold-email agencies, 2026

Private beta

klaroh.onlineProject notes on GitHub

The problem
Agencies running cold email for several clients struggle to keep an eye on each client’s campaign performance and sending health, and end up reporting with screenshots and PDFs.
What I built
A multi-tenant dashboard that syncs campaign data from Instantly, shows every client’s campaigns, replies and mailbox health in one place, and gives each client a private, branded report that opens without a login. Workspaces are isolated with row-level security, provider keys are encrypted, and any metric whose source cannot be verified is left out rather than guessed.
What works today
Instantly is the only connected sending tool. Data is synced on a schedule and on demand, not live. Klaroh reads campaign data and never sends email. The application code lives in a separate private repository.

GTM Validation Tool

Lead list validation, 2026

Working code

Code and README

The problem
Verifying every email in a raw lead list costs money, and long verification runs fail halfway through when a provider rate-limits or a request times out.
What I built
A Next.js and Supabase app that imports a CSV, scores each lead against the project’s ICP with structured AI output, and only then verifies emails through Clearout. Verification runs on a PostgreSQL job queue that claims work with leases, retries failures, handles rate limits and logs API cost, so a job can pause and resume without paying for the same check twice.
What works today
The import, scoring and verification flow is implemented. Automated test coverage is incomplete and build-time type checking is disabled; both are listed as open work in the README.

Signal-to-pipeline workflows

n8n automation, 2025 to 2026

Importable workflows

Workflow files and READMEs

The problem
Lists exported from a database are weeks old by the time anyone emails them, and enriching every row burns budget on contacts that never fit.
What I built
Two n8n systems. The first starts from live hiring signals and runs the cheap checks before the paid one, storing every score with its written reason. The second sends from the qualified queue on a controlled cadence and records opens with a self-hosted pixel.
What works today
These are workflow files, not a hosted product. Running them needs your own n8n instance and API keys for Apify, Gemini, Clearout, Airtable, Claude and Gmail.
  1. SignalApify pulls job postings by industry and role
  2. ScoreGemini checks ICP fit and writes why
  3. GradeEmail quality scored 0 to 100, with reasons
  4. VerifyClearout checks only the leads that passed
  5. QueueAirtable marks the lead safe to send
  6. SendClaude rewrites each email; Gmail sends with random gaps
  7. TrackA self-hosted pixel records the open

A lead that fails the ICP check stops at step 2, so it never costs a verification credit.
