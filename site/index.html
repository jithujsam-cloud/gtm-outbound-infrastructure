The pipeline

From job posting to opened email.

This is how my systems handle one lead. Cheap checks run first, so paid verification only goes to leads that have already passed.

  1. 01

    Catch the signal Apify

    Pull job postings filtered by industry and role. A hiring spike is a buying signal.

  2. 02

    Score the account Gemini

    Score each lead against the ICP verticals, with a written reason for every match or miss.

  3. 03

    Grade the email Point system

    Structure, name match, domain match and a penalty for generic prefixes like info@ and sales@.

  4. 04

    Verify only what passed Clearout

    SMTP verification runs last and only on qualified leads, so no money goes to dead ones.

  5. 05

    Queue it Airtable

    Valid, ICP-matched contacts get upserted and marked Safe to Send.

  6. 06

    Send like a human Claude · Gmail

    Weekdays, 9 to 6, up to 4 emails per run with a random 0–5 minute gap. Claude rewrites every email so no template goes out twice.

  7. 07

    Track the open Webhook pixel

    A self-hosted 1×1 pixel fires a webhook and stamps "Opened On" in Airtable. No third-party tracking domain.
